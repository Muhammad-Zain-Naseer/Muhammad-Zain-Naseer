## 🧩 Selected work

**Atom Manager · DipGos** — *INDUS Technologies · in use at WAPDA*
Built the module from the React/TypeScript frontend to the FastAPI/PostgreSQL backend. It tracks every worker, machine and material on a project in one live catalogue, with demand and schedule forecasts, reporting APIs and a step-by-step creation wizard that validates each step.

**LinkedIn Ads → HubSpot sync** — *Attributter · part-time, remote*
A Redis/BullMQ job system that syncs 10,000+ companies every day without blocking, chaining parent and child API calls per user inside the rate limits. Added a token-bucket limiter, JWT auth, request validation, and CI/CD with Docker and GitHub Actions.

**HerSafar** — *final-year project · backend and deployment*
Voice-first ride sharing for women who can't comfortably read or type. Urdu audio goes straight to Gemini and comes back as a structured JSON ride request, with live driver tracking, SOS alerts, buddy pairing and trusted-contact sharing. Ran on Oracle Kubernetes Engine with a GitHub Actions pipeline.
→ [Write-up](https://zainnaseer.com/project.html?p=hersafar)

**SensAI** — *AI in Healthcare Initiative, LUMS*
Led full-stack development of a tool that transcribes doctor–patient consultations with Gemini and turns them into structured clinical notes, on a backend built to handle patient data under HIPAA rules.

**AI automations** — *n8n · OpenAI · Vertex AI*
A WhatsApp assistant that keeps per-user memory and picks its own tools (web search, Google Calendar, Google Sheets), and a lead follow-up workflow that writes a tailored email or SMS for every new CRM lead and validates the model's output before anything is sent.
→ [WhatsApp assistant](https://zainnaseer.com/project.html?p=whatsapp-ai-assistant) · [Lead follow-up](https://zainnaseer.com/project.html?p=ai-lead-follow-up)

**Urdu News Classifier** — *ML coursework*
Naive Bayes reached **97.6%** test accuracy on Urdu news, ahead of a neural network (95.2%) and logistic regression (94%).
→ [Code](https://github.com/Muhammad-Zain-Naseer/UrduNewsClassifier)
